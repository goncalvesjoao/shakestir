# Wordmark

`app/assets/images/branding/wordmark-normal.png` and `wordmark-hover.png` are transparent 4× PNG renders of the original font-based logo without the dot. Chromium rendered DM Sans Bold at 28px with -0.07em tracking and a Playfair Display Medium Italic ampersand with 2px side margins. Normal ink is #202923; hover ink is #486139. Both files share the same dimensions so hovering preserves placement. The shared wordmark partial provides an accessible name and swaps the visible image on link hover. No font downloads occur in the app.

Source fonts: Google Fonts DM Sans v17 and Playfair Display v40. Their SIL Open Font Licenses are retained here for the rendered artwork.
