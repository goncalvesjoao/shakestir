# Technique catalog

`catalog.json` contains original practical explanations for 17 preparation techniques. These are educational interface fixtures; their descriptions and instructions were written for this project rather than copied from a source database.

Demo recipes explicitly list technique slugs in `../demo/recipes.json` and `../demo_accounts.json`. The prototype seeds these links alongside ordered preparation steps and retains existing curated assignments on reruns. It does not infer techniques from arbitrary user prose. FastAPI does not yet implement techniques.
